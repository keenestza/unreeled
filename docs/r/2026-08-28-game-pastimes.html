Pastimes

Released 2026-08-28

Pastimes is a calm 2D logic puzzle based on Pieter Bruegel the Elder's painting Children's Games (1560). Players fill a large numbered grid where each clue indicates how many cells must be filled in the surrounding 3×3 area. Solving the puzzle gradually reveals the full painting, divided into scenes
